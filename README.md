One cinematic image summing up Tuesday 17 November 2026's world news: the
Kerch Bridge at dusk under drone attack, the Kyiv skyline in the distance,
and a caption strip naming the day plus five headlines — Kerch/Kyiv bridge
strikes, the Iran drone hit on the U.S. radar base in Bahrain, the
Xi–Trump–Putin meeting set for Shenzhen, Estonia's border shutdown, UK
sanctions, Japan scrambling jets, and the Houthi advance on Aden.

The image is drawn entirely in code (`generate.py`, PIL) — no photos.

## Run

```sh
python3 generate.py        # regenerate entry.png (1024x1024, <= 1 MiB)
MAKEFUN_OUTPUT_DIR=out python3 main.py   # copy entry.png to out/entry.png
```
